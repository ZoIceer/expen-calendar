功能说明与验收标准

产品规划 · 界面设计 · 交互设计 · 前端实现 四角色协作产出

一、功能结构

  • P0：自然月日历网格；任意日期新增 / 编辑 / 删除；名称、分类、备注、金额、日期均可改；每日 / 每周 / 每月自动汇总；localStorage 持久化；示例数据。
  • P1：月份切换与「今天」；分类占比；删除确认与 5 秒撤销；JSON 导出 / 导入；主题切换；示例数据一键清空。
  • P2：环比提示；键盘导航（方向键切日、Ctrl/Cmd+Z 撤销、Esc 关闭）；响应式布局。

二、页面布局

顶部栏（品牌 / 月份导航 / 工具）→ 汇总条（月总额、笔数、日均、最高单日、所选周合计）→ 主体左栏 6 行 × 7 列日历 + 行末周合计列，右栏分类占比与当日明细。≥1180px 双栏；760–1180px 侧栏下移；<760px 单列并压缩单元格。

三、交互规则

  • 单击日期格 → 选中并刷新右侧明细；双击日期格或点 ＋ → 新增；点条目 → 编辑。
  • 删除 → 二次确认 → Toast 中 5 秒内可撤销；清空数据同样需确认。
  • 金额必须 > 0、最多 2 位小数、≤ 10 亿；名称 1–30 字必填；备注 ≤ 100 字。
  • 邻月日期灰显但可记账，记录归入其真实所属月；跨月周合计含邻月日期。
  • 数据变更后即时重算所有合计；导入 JSON 按 ID 去重并校验非法项。

四、验收标准

  • 日历按周一起点渲染 6 行，当月日期与邻月日期状态区分正确。
  • 新增 / 编辑 / 删除后，所在日、所在周、当月合计同步更新且数值正确。
  • 分类占比合计等于当月总支出；周合计等于该行 7 天之和。
  • 月合计只含当前自然月；环比在上月为 0 时安全显示「上月无数据」。
  • 刷新页面数据不丢失；存储损坏时降级为空数据并给出警示，不白屏。
  • 表单校验拦截空值、负数、非数字、超长文本；超大金额正常显示千分位。
  • 删除确认与撤销、清空确认、导入导出、主题切换均按规则工作。
