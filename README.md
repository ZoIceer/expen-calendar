# 月度消费日历

一个可交互的移动端月度消费日历，支持按日 / 周 / 月汇总、分类占比、JSON 导出导入、明暗主题切换。数据保存在浏览器本地（localStorage），不上传服务器。

## 本地使用

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## GitHub Pages

本仓库可直接作为静态站点发布：

1. 仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选择 `main`，目录选 `/ (root)`
4. 保存后等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

`.nojekyll` 文件用于确保 Pages 不做额外处理。
